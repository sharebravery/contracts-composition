# Security Policy

This repository contains educational smart contracts and testnet deployments. Do not use the deployed contracts with production assets.

## Reporting a Vulnerability

Please do not publish exploitable details in a public issue. Use GitHub's private vulnerability reporting flow for this repository when available. Include the affected contract or package, the impact, reproduction steps, and a suggested fix when possible.

Never include private keys, API keys, seed phrases, or other credentials in a report.
